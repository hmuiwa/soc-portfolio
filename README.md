# Haron Muiwa — SOC Analyst Portfolio

A responsive, dependency-free portfolio website built with HTML, CSS and JavaScript.

## Preview locally

Open `index.html` directly in a browser, or run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customisation

- Update the profile and lab descriptions in `index.html`.
- Change the colour palette and layout in `styles.css`.
- Update the LinkedIn URL or email address in `index.html`.
